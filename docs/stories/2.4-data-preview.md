# Story 2.4: Data Preview

## Status

InProgress

## Story

**As a** user,  
**I want** to preview the first 10 rows of my uploaded data,  
**so that** I can verify the data was uploaded and parsed correctly.

## Acceptance Criteria

1: Endpoint `GET /api/v1/upload/{id}/preview` truy xuất head dữ liệu, trả về JSON bao gồm 10 dòng đầu kèm column data typings.
2: Response bao gồm thêm loại data type hệ thống đã tự động detect ra và thông tin column statistics cơ bản.
3: Trả về `404 Not Found` nếu truyền thông số `dataset_id` không tồn tại.

## Tasks / Subtasks

- [ ] Task 1: Building Controller (AC: 1, 3)
  - [ ] Wire `GET /api/v1/upload/{id}/preview` internally via `{backend}/app/api/endpoints/upload.py`.
  - [ ] Check DB context returning `404 Not Found` if UUID fails queries.
- [ ] Task 2: Service Level Data Assembly (AC: 1, 2)
  - [ ] Ask MinIO wrapper in `{backend}/app/services/storage.py` to stream just the head or read `nrows=10` leveraging Pandas.
  - [ ] Combine response combining `.head(10).to_dict(orient="records")`, column native type inferences, and basic statistic maps.

## Dev Notes

### Relevant Source Tree

- Optimize streams explicitly: prevent fetching a full 100MB chunk just to answer a Head query. Seek partial byte structures or use `pd.read_csv(filepath, nrows=10)` equivalents.

### Tech Stack

- Pandas read configurations.

### Testing

- **Location**: `{backend}/tests/test_upload.py`
- **Type**: Request a non-existent UUID ensuring a valid explicit 404 message block appears. Request a valid endpoint checking schema length arrays map properly to `10`.
