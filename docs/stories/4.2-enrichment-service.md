# Story 4.2: Enrichment Service

## Status

Review

## Story

**As a** developer,
**I want** aggregated anomaly clusters enriched with numerical reasoning signals, priority ranking, and semantic text,
**so that** the LLM can generate accurate reports without performing any calculations.

## Acceptance Criteria

1: `{ai_services_generation}/src/enrichment/enrichment_service.py` implement `EnrichmentService` class
2: `EnrichmentService.enrich(aggregated_data)` thêm cho mỗi cluster: `ratio` (VD: "1.34% of total"), `priority` (1-3), `impact_score` (0-1), `impact` level (High/Medium/Low)
3: Priority ranking dựa trên `impact_score`: score ≥0.8 → priority 1, ≥0.5 → priority 2, còn lại → priority 3
4: Sinh `semantic_text` cho detailed reports: "Price is 45% higher than district average", "Commission is 80% higher than expected"
5: Individual anomaly detail chứa: `risk_level`, `anomaly_score`, `key_findings[]`, `location_context`, `temporal_context`
6: Output JSON đạt chuẩn "Semantic & Enriched" — LLM có thể viết report chỉ bằng cách rewrite
7: Unit tests tại `{ai_services_generation}/tests/test_enrichment.py`

### Patterns & Conventions

- **Python naming**: `snake_case` for files/modules, `PascalCase` for classes (e.g., `EnrichmentService`)
- **Type hints**: Use `X | Y` union syntax (Python 3.10+), type all public method signatures
- **Docstrings**: Google-style `"""triple-quote"""` with `Args:` and `Returns:` sections
- **Config-driven**: All thresholds (impact_score boundaries, priority mapping) in `configs/generation_config.yaml`
- **Logging**: Use centralized `get_logger(name)` pattern, `%s` string formatting
- **Data flow**: Input is `AggregationResult.to_dict()` from Story 4.1, output is `EnrichmentResult.to_dict()` for Story 4.6
- **No framework**: Pure Python — follows detection pipeline pattern

### Tech Stack

- **Python** >=3.10 (union type syntax)
- **NumPy** >=1.24.0 — numerical computations for scoring
- **PyYAML** >=6.0 — config loading for thresholds
- **pytest** >=7.4.0 — unit testing

### Notes from Previous Stories

- Cluster structure: `issue_type`, `count`, `samples[]`, `affected_ids[]` — enrich these fields in-place
- Context summary (`total_records`, `expected`, `missing`, `anomaly_ratio`) available for ratio computation

### Testing
