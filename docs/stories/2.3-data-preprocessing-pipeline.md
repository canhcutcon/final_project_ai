# Story 2.3: Data Preprocessing Pipeline

## Status

Approved

## Story

**As a** user,  
**I want** my data to be automatically cleaned and preprocessed,  
**so that** it's ready for anomaly detection inference.

## Acceptance Criteria

1: Module `DataService.preprocess()` thực hiện đầy đủ các bước chuẩn hóa cơ bản: xử lý missing values, mã hóa categorical (encoding), căn chỉnh tỉ lệ numeric (scaling).
2: Tạo object `PreprocessResult` chứa summary chi tiết: danh sách cột processed, số hàng bị bỏ đi do lỗi/rỗng, và các thuật toán transform đã được sử dụng.
3: Dữ liệu chuẩn hoá xử lý sau cùng được gán lưu lại MinIO thành một file processed CSV (khác với gốc).

## Tasks / Subtasks

- [ ] Task 1: Preprocessing Core Logic (AC: 1)
  - [ ] Create wrapper orchestrating logic in `{ai_services_detection}/src/data/cleaning.py` and `{ai_services_detection}/src/data/transforms.py`.
  - [ ] Handle missing imputation cleanly.
  - [ ] Standardize numbers scaling and encode labels (Ordinal or Nominal strings).
- [ ] Task 2: Object Wrapping and Output Transport (AC: 2, 3)
  - [ ] Track column alterations returning summarized dictionaries representing `PreprocessResult`.
  - [ ] Push the final memory DataFrame payload to MinIO saving using path suffix `_processed.parquet` or CSV.
  - [ ] Link Processed status metrics via Database connection.

## Dev Notes

### Relevant Source Tree

- `{backend}/app/services/data_service.py`
- Context relies directly on actual logic inside: `{ai_services_detection}/src/data/cleaning.py` and `SchemaStandardizer`.
- `{backend}/app/services/storage.py`

### Patterns & Conventions

- Maintain single-responsibility where Data Pipelines only yield resulting signals. Let routers control IO returns.
- Save processed sets mostly in `.parquet` natively utilizing `pandas.to_parquet()` leveraging PyArrow.

### Tech Stack

- Pandas 2.0.0+ (PyArrow Backend)
- Scikit-learn (Transformers/Imputers)
- MinIO SDK

### Testing

- **Location**: `{backend}/tests/test_data_services.py`
- **Type**: Create mocked messy `sample_df` dataframes capturing null values and verifying output `PreprocessResult` accurately describes drop thresholds.
