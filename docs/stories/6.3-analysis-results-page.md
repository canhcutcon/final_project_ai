# Story 6.3: Analysis Results Page

## Status

Draft

## Story

**As a** user,  
**I want** to see anomaly detection results with visual heatmaps and highlighted rows,  
**so that** I can quickly identify problematic data rows.

## Acceptance Criteria

1: Xây dựng biểu đồ nhiệt (Score Heatmap) kết cấu từ chuỗi điểm anomaly scores trả về bởi API (TranAD / BiLSTM / AnoGAN).
2: Phân trang Data Table (`AnomalyTable`), bôi sáng (highlighted) bằng cảnh báo màu đỏ trực tiếp các row/cột có nguy cơ dị thường.
3: Rendering `AnomalyChart`: bar chart hiển thị phân bố độ mật độ score dị thường.
4: Chức năng Filter, sắp xếp sort theo anomaly_score hoặc row_idx tiện lợi cho Data Analyst.

## Tasks / Subtasks

- [ ] Task 1: Metric Charts Construction (AC: 1, 3)
  - [ ] Implement `ScoreHeatmap` logic mapping severity indexes utilizing matrix visualizations or detailed continuous charts (Recharts).
  - [ ] Build `AnomalyChart` histogram mapping density to display threshold buckets.
- [ ] Task 2: Interactive Grids (AC: 2, 4)
  - [ ] Construct the `AnomalyTable` utilizing an advanced robust table mechanism parsing the full analysis results array.
  - [ ] Paint logical conditions dynamically highlighting styling rules (`neon red` bg classes for rows surpassing score bounds).
  - [ ] Hook Sort logic reversing `anomaly_score` or filtering down explicit `row_indices`.

## Dev Notes

### Relevant Source Tree
- `{bafrontend}/src/app/analysis/[id]/page.tsx`
- `{bafrontend}/src/components/Analysis/`

### Patterns & Conventions
- Paginate massive grids heavily: 10k rows will crash the DOM if not virtualized or Server-Paginated. Assume backend guarantees structured offset boundaries or we implement `react-window`/`tanstack-table`.
- Keep complex Recharts computations bundled tightly isolating explicit re-renders inside `"use client"`.

### Tech Stack
- React Virtualized / TanStack Table
- Recharts (Scatter/Heat maps)
- TailwindCSS conditionals (`clsx` or `tailwind-merge` recommended)

### Testing
- **Location**: `{bafrontend}/src/__tests__/analysis.test.tsx`
- **Type**: Inject array payload mocked responses checking dynamic rendering length limits and proper style attributions on scores `> 0.8`.
