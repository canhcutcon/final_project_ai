# Story 6.4: Report Viewer & PDF Download

## Status

Draft

## Story

**As a** user,  
**I want** to view the generated NLP report and download it as PDF,  
**so that** I can read and present analytical insights conveniently to stakeholders.

## Acceptance Criteria

1: Hiển thị component `ReportViewer`: biên dịch engine render markdown format từ response của mô hình Qwen2.5-7B ra frontend.
2: Tích hợp thanh tùy chọn cấu hình `Report Config`: Ngôn ngữ (tiếng Việt/Anh) và độ dài chi tiết (summary/detailed).
3: Nút `PDFExport` hiển thị preview PDF ảo và call API `/download` để stream file tải về máy Client trực tiếp.

## Tasks / Subtasks

- [ ] Task 1: View Generation Engine (AC: 1)
  - [ ] Develop `ReportViewer` leveraging `react-markdown` applying custom tailwind typography plugins.
  - [ ] Securely render markdown ensuring any potentially unsafe injection is neutralized.
- [ ] Task 2: Config and Action Utilities (AC: 2, 3)
  - [ ] Implement toggle configurations bound to parent state triggering `NLP` parameters re-generation if modified (`EN/VI`, `detailed`).
  - [ ] Build `PDFExport` button bound asynchronously awaiting `/download` streams triggering a Blob object URL save routine mapping to local harddisks.

## Dev Notes

### Relevant Source Tree
- `{bafrontend}/src/app/report/[id]/page.tsx`
- `{bafrontend}/src/components/Report/`

### Patterns & Conventions
- Markdown components should intercept typical rules mapping lists and bold headers directly to Next.js compliant visual tags leveraging standard Typography utilities.
- Avoid building client-side PDFs manually (e.g. jspdf). Rely entirely on backend's ReportLab backend streaming binary blobs.

### Tech Stack
- `react-markdown`
- `@tailwindcss/typography`
- Fetch API (for blob reading).

### Testing
- **Location**: `{bafrontend}/src/__tests__/report.test.tsx`
- **Type**: Component unit testing ensuring markdown strings output safe and visually exact `<p>` string html fragments.
