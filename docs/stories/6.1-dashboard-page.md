# Story 6.1: Dashboard Page

## Status

Draft

## Story

**As a** user,  
**I want** a dashboard showing overview statistics and recent analyses,  
**so that** I have a quick glance at my data activity.

## Acceptance Criteria

1: Hiển thị metrics tổng quan: tổng số lượng datasets, tổng số report đã sinh, tỉ lệ phát hiện dị thường (anomaly detection rate).
2: Render danh sách bảng dữ liệu 5 analyses gần nhất cùng với `status` (Running, Completed, Failed).
3: Đồ thị Charts tổng quan vẽ bằng thư viện màn hình (Recharts hoặc D3.js).

## Tasks / Subtasks

- [ ] Task 1: Initialize App Routing (AC: 1)
  - [ ] Generate `{bafrontend}/src/app/(dashboard)/page.tsx` defining the main grid layout layout.
  - [ ] Implement server-side data fetching hitting the backend `API` for high-level metrics (Total count wrappers).
- [ ] Task 2: Build Metric Cards and Tables (AC: 1, 2)
  - [ ] Develop a reusable MetricCard displaying KPI metrics dynamically mapping `Total Runs` & `Detection Rate`.
  - [ ] Develop `{bafrontend}/src/components/Dashboard/RecentAnalysisTable.tsx` filtering states. Use green text for 'Completed', red for 'Failed', amber/animated for 'Running'.
- [ ] Task 3: Data Visualization Integration (AC: 3)
  - [ ] Build a generic `{bafrontend}/src/components/Dashboard/OverviewChart.tsx` implementing a `Recharts` responsive container for chronological trends.
