# Story 6.3: CSV Upload Page

## Status

Draft

## Story

**As a** user,
**I want** to drag-and-drop CSV files, preview structure data, select data archetype and AI model before initializing analysis,
**so that** I can verify and configure my data ingestion accurately.

### Patterns & Conventions

- **Design reference**: `{frontend}/UI/upload_page/upload_page_code.html` + `upload_page_screen.png` are pixel-perfect guides.
- **Drag-Drop**: Use native HTML5 drag-and-drop events (onDragEnter/Over/Leave/Drop). No third-party drag library needed.
- **"No-Line" Rule**: Data table uses `divide-y divide-outline-variant/10` (very subtle), NOT solid 1px borders. No vertical lines.
- **Fluid Row Table**: No `border-collapse` visible borders. Hover state via background color shift `bg-surface-container-low`.
- **Ghost Border on Drop Zone**: `border-2 border-dashed border-primary/20` — dashed is allowed per design system for drop zones (2px dash, 4px gap).
- **File upload API**: `POST /api/v1/upload` accepts `multipart/form-data` with CSV file.
- **Preview API**: `GET /api/v1/upload/{id}/preview` returns 10 rows + column info + detected data type.
