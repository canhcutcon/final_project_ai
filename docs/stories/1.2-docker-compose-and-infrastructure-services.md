### Patterns & Conventions

- **Dockerization Standard**: Anchor versions strictly (e.g., `mysql:8.0.35` instead of `:latest`).
- **Data Safety**: Always use named docker volumes preventing manual purging or ephemeral data loss.
- **Port Masking**: Map the services carefully to avoid Port conflict on developer machines.

### Tech Stack

- **Container Technology**: Docker Compose (v2)
- **Database**: MySQL 8.0+
- **Message Broker/Cache**: Redis
- **Cloud Scale Storage**: MinIO object datastore.

### Testing

- **Type**: Functional / Local Integration.
- Expected assertion: executing `docker-compose up -d` correctly spawns all services simultaneously without crashloops.
