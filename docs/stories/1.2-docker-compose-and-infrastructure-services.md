# Story 1.2: Docker Compose & Infrastructure Services

## Status

Approved

## Story

**As a** developer,  
**I want** all infrastructure services (MySQL, Redis, MinIO) running via Docker Compose,  
**so that** the development environment is reproducible and isolated.

## Acceptance Criteria

1: Lệnh `docker-compose up` khởi động thành công các container: backend, celery-worker, mysql, redis, minio, frontend.
2: Thiết lập volumes persistent an toàn cho MySQL data để tránh mất dữ liệu khi restart.
3: MinIO console có thể truy cập thành công tại port `9001` từ localhost.

## Tasks / Subtasks

- [ ] Task 1: Dockerize the Backend app (AC: 1)
  - [ ] Implement `{backend}/Dockerfile` leveraging a Python 3.11 minimal base image.
  - [ ] Enable support for running the FastAPI web worker and Celery async workers from the same Dockerfile.
- [ ] Task 2: Configure Core Infrastructure in Compose (AC: 1, 2)
  - [ ] Initialize `docker-compose.yml` at project root `giang_workspace/`.
  - [ ] Establish a `mysql:8.0` service with persistent volume mappings (e.g. `./volumes/mysql_data`).
  - [ ] Establish a `redis:alpine` service required for the Celery message broker.
- [ ] Task 3: Configure MinIO Object Storage (AC: 1, 3)
  - [ ] Run the official `minio/minio` service, mapped firmly to Port `9000` (API binding) and `9001` (Console Server).
  - [ ] Define a `Minio_volume` to ensure file uploads endure across tear downs.
- [ ] Task 4: Connect Workloads to Docker (AC: 1)
  - [ ] Integrate a `backend` service leveraging the `{backend}/Dockerfile`.
  - [ ] Integrate a `celery_worker` service passing the appropriate entrypoint.

## Dev Notes

### Relevant Source Tree

- `giang_workspace/docker-compose.yml`
- `{backend}/Dockerfile`
- `{backend}/.env.example`

### Patterns & Conventions

- **Dockerization Standard**: Anchor versions strictly (e.g., `mysql:8.0.35` instead of `:latest`).
- **Data Safety**: Always use named docker volumes preventing manual purging or ephemeral data loss.
- **Port Masking**: Map the services carefully to avoid Port conflict on developer machines.

### Tech Stack

- **Container Technology**: Docker Compose (v2)
- **Database**: MySQL 8.0+
- **Message Broker/Cache**: Redis
- **Cloud Scale Storage**: MinIO object datastore.

### Testing

- **Type**: Functional / Local Integration.
- Expected assertion: executing `docker-compose up -d` correctly spawns all services simultaneously without crashloops.
