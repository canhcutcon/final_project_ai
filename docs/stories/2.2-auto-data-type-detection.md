# Story 2.2: Auto Data Type Detection

## Status

Approved

## Story

**As a** user,  
**I want** the system to automatically detect if my data is tabular, time-series or mixed,  
**so that** the appropriate AI model is selected implicitly.

## Acceptance Criteria

1: Hệ thống `DataService.detect_data_type()` tự động phân loại chính xác 3 loại dữ liệu: `tabular`, `timeseries`, `mixed`.
2: Lưu kết quả nội dung nhận diện vào cột `data_type` của bản ghi dataset trong bảng `datasets`.
3: Thuật toán nhận diện dựa trên phân tích đặc trưng các cột dữ liệu (ví dụ: có mặt cột datetime, sequential ID patterns).

## Tasks / Subtasks

- [ ] Task 1: Type Detection Engine (AC: 1, 3)
  - [ ] Expand logic under `{backend}/app/services/data_service.py` referencing the AI profiling patterns defined in `{ai_services_detection}/src/data/profiler.py`.
  - [ ] Load the DataFrame stream. Check for `datetime` native columns or `SubmitDate`/sequence markers to infer target categories (`timeseries` vs `tabular`).
- [ ] Task 2: Persistence to Database (AC: 2)
  - [ ] Execute an `UPDATE` mapped to the ORM `Dataset` binding the inferred `data_type` enum properly.
