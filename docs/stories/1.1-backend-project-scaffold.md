### Patterns & Conventions

- **Language Requirements**: Python 3.11+ using explicit type hints (union types like `X | Y`).
- **Logging Strategy**: Use `get_logger(name)` and format via `%s` standard (`logger.info("... %s", value)`). Do NOT rely on f-strings internally pending architecture rules.
- **State Management**: No global state. Dependencies and settings should be validated with Pydantic schemas.

### Tech Stack

- **Framework**: FastAPI (Async)
- **ASGI Server**: Uvicorn
- **Validation**: Pydantic BaseSettings

### Testing

- **Framework**: `pytest >= 7.4`
- **Test File Location**: `{backend}/tests/test_main.py`
- **Type**: API Unit Testing utilizing `fastapi.testclient.TestClient`.
