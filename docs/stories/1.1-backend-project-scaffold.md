# Story 1.1: Backend Project Scaffold

## Status

Approved

## Story

**As a** developer,  
**I want** to scaffold the FastAPI backend project with proper folder structure,  
**so that** the team has a standardized codebase to build upon.

## Acceptance Criteria

1: Cấu trúc `{backend}/app/` với các thư mục `api/`, `core/`, `models/`, `schemas/`, `services/`, `ml/` được thiết lập đúng chuẩn.
2: `main.py` chạy thành công với endpoint `/health` trả về `200 OK`.
3: `config.py` đọc đúng các biến môi trường (env vars) cho Database, Redis, MinIO, JWT secret.

## Tasks / Subtasks

- [ ] Task 1: Setup project structure (AC: 1)
  - [ ] Create folder structure under `{backend}/app/`: `api/`, `core/`, `models/`, `schemas/`, `services/`, `ml/`
  - [ ] Initialize `requirements.txt` (or pyproject.toml) with FastAPI, Uvicorn, Python-dotenv, Pydantic settings.
- [ ] Task 2: Implement Configuration Manager (AC: 3)
  - [ ] Create `{backend}/app/core/config.py` using Pydantic `BaseSettings` to safely read env vars (DB, Redis, MinIO, JWT).
  - [ ] Create `.env.example` placeholder in `{backend}/`.
- [ ] Task 3: Setup FastAPI App & Healthcheck Endpoint (AC: 2)
  - [ ] Create `{backend}/app/main.py` orchestrating the FastAPI instance.
  - [ ] Implement `GET /health` inside `api` or `main.py` returning `{"status": "ok"}`.
- [ ] Task 4: Setup Logging & Testing Conventions
  - [ ] Write a centralized logger compatible with `utils.helpers.get_logger`.
  - [ ] Write a basic pytest verification for the `/health` endpoint.

## Dev Notes

### Relevant Source Tree

- `{backend}/` (Currently empty, initialized here)
- `{backend}/app/main.py` (API entrypoint)
- `{backend}/app/core/config.py` (Configurations)

### Patterns & Conventions

- **Language Requirements**: Python 3.11+ using explicit type hints (union types like `X | Y`).
- **Logging Strategy**: Use `get_logger(name)` and format via `%s` standard (`logger.info("... %s", value)`). Do NOT rely on f-strings internally pending architecture rules.
- **State Management**: No global state. Dependencies and settings should be validated with Pydantic schemas.

### Tech Stack

- **Framework**: FastAPI (Async)
- **ASGI Server**: Uvicorn
- **Validation**: Pydantic BaseSettings

### Testing

- **Framework**: `pytest >= 7.4`
- **Test File Location**: `{backend}/tests/test_main.py`
- **Type**: API Unit Testing utilizing `fastapi.testclient.TestClient`.
