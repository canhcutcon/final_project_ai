# Story 4.7: PDF Export

## Status

Draft

## Story

**As a** user,
**I want** to download the analysis report as a PDF,
**so that** I can share it with stakeholders.

## Acceptance Criteria

1: `NLPService.export_pdf(report_id)` chuyển Markdown content sang PDF (ReportLab/WeasyPrint)
2: PDF engine hỗ trợ Unicode tiếng Việt đầy đủ (font: Noto Sans Vietnamese)
3: PDF layout: header (logo + title), footer (page numbers), margins, professional typography
4: Bao gồm charts/tables nếu có trong report (render từ data)
5: PDF lưu vào MinIO bucket `reports`: `{user_id}/{report_id}/report.pdf`
6: `pdf_path` cập nhật trong bảng `reports`
7: `GET /api/v1/report/{id}/download` stream PDF về client với header `Content-Disposition: attachment`
8: Trả `404` nếu report chưa có PDF, `403` nếu không phải owner

## Tasks / Subtasks

- [ ] Task 1: Set up PDF engine and Vietnamese font (AC: 1, 2)
  - [ ] Choose PDF engine: WeasyPrint (HTML/CSS → PDF, better for complex layouts) or ReportLab (programmatic PDF, better for charts)
  - [ ] Add PDF library to `{backend}/requirements.txt` (`weasyprint` or `reportlab`)
  - [ ] Download and configure Noto Sans Vietnamese font — store in `{backend}/app/ml/generation/fonts/NotoSans-Vietnamese/`
  - [ ] Implement `{backend}/app/ml/generation/pdf_engine.py` with `PDFEngine` class
  - [ ] Implement `markdown_to_pdf(markdown_content, language, metadata) -> bytes` — convert Markdown to PDF
  - [ ] If using WeasyPrint: convert Markdown → HTML (via `markdown` library) → apply CSS → render PDF
  - [ ] If using ReportLab: parse Markdown sections → build PDF canvas with Platypus flowables
  - [ ] Verify: Vietnamese characters render correctly (diacritics: ă, â, đ, ê, ô, ơ, ư)

- [ ] Task 2: Implement PDF layout (AC: 3)
  - [ ] Design page template: A4 size, margins (top: 2.5cm, bottom: 2cm, left: 2.5cm, right: 2cm)
  - [ ] Header: company logo placeholder (left), report title (center), date (right)
  - [ ] Footer: page number (center), "Generated by CSV Agent Platform" (right)
  - [ ] Typography: Noto Sans Vietnamese, body 11pt, headings 14pt/12pt, line spacing 1.4
  - [ ] Section styling: bold headers, horizontal rules between sections, indented bullet points
  - [ ] Color scheme: professional (dark text #333, headers #1e3a5f, accent #4a9eff)

- [ ] Task 3: Implement charts and tables rendering (AC: 4)
  - [ ] Implement `_render_table(data, headers) -> PDFElement` — format tabular data as PDF table with borders, alternating row colors
  - [ ] Implement `_render_chart(chart_data, chart_type) -> PDFElement` — generate bar/pie chart from anomaly statistics (using matplotlib → image → embed in PDF)
  - [ ] Auto-generate summary chart: anomaly distribution by issue_type (bar chart)
  - [ ] Auto-generate priority table: clusters ranked by priority with impact scores
  - [ ] Handle reports without charts/tables gracefully — skip chart section

- [ ] Task 4: Implement MinIO storage and database update (AC: 5, 6)
  - [ ] Implement `_upload_to_minio(pdf_bytes, user_id, report_id) -> str` — upload PDF to MinIO bucket `reports` at path `{user_id}/{report_id}/report.pdf`
  - [ ] Reuse existing `MinioService` from `{backend}/app/services/storage.py` — ensure bucket `reports` exists (create if not)
  - [ ] Update `reports` table: set `pdf_path` field with MinIO object path
  - [ ] Add `pdf_path` column to Report model if not exists — create Alembic migration

- [ ] Task 5: Implement export_pdf method in NLPService (AC: 1)
  - [ ] Add `export_pdf(report_id, user_id) -> str` method to `{backend}/app/services/nlp_service.py`
  - [ ] Load report from database by `report_id`
  - [ ] Convert report `content` (Markdown) to PDF via `PDFEngine.markdown_to_pdf()`
  - [ ] Upload PDF to MinIO via `_upload_to_minio()`
  - [ ] Update `pdf_path` in reports table
  - [ ] Return MinIO path or download URL

- [ ] Task 6: Implement download API endpoint (AC: 7, 8)
  - [ ] Add `GET /api/v1/report/{id}/download` to `{backend}/app/api/endpoints/report.py`
  - [ ] Load report from database — return `404` if not found or `pdf_path` is null ("Report PDF not generated yet")
  - [ ] Check ownership — return `403` if requesting user is not report owner
  - [ ] Stream PDF from MinIO using `MinioService.download()` → `StreamingResponse`
  - [ ] Set headers: `Content-Type: application/pdf`, `Content-Disposition: attachment; filename="report_{id}.pdf"`

- [ ] Task 7: Write tests (AC: 1-8)
  - [ ] Create `{backend}/tests/test_pdf_export.py`
  - [ ] Test Markdown → PDF conversion with Vietnamese content
  - [ ] Test PDF layout: verify page count, headers, footers (use `PyPDF2` or `pdfplumber` to inspect)
  - [ ] Test chart and table rendering in PDF
  - [ ] Test MinIO upload: mock `MinioService`, verify correct path and bucket
  - [ ] Test database update: verify `pdf_path` field updated after export
  - [ ] Test download endpoint: mock MinIO download, verify StreamingResponse with correct headers
  - [ ] Test 404 for non-existent report
  - [ ] Test 403 for non-owner access

### Patterns & Conventions

- **Backend architecture**: Layered — endpoint calls service, service calls storage + ML layer
- **MinIO integration**: Reuse `MinioService` from `{backend}/app/services/storage.py` — pattern: `minio_service.upload(bucket, path, data)`
- **Database migrations**: Alembic — create new migration script for `pdf_path` column
- **Error handling**: `HTTPException(status_code=404, detail="...")` / `HTTPException(status_code=403, detail="...")`
- **Streaming response**: FastAPI `StreamingResponse` for large file downloads
- **Python naming**: `snake_case` for files, `PascalCase` for classes
- **API response**: No standardized envelope — raw JSON for errors, streaming bytes for PDF
