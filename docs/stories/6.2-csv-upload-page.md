# Story 6.2: CSV Upload Page

## Status

Draft

## Story

**As a** user,  
**I want** to drag-and-drop CSV files and preview data before analysis,  
**so that** I can verify the correct file is uploaded safely.

## Acceptance Criteria

1: Xây dựng component UI `CSVUploader`: hỗ trợ drag-drop zone rõ ràng và hiển thị error validation (dung lượng/định dạng).
2: Xây dựng component `CSVPreview`: kết xuất hiển thị data table minh bạch lấy từ 10 mẫu dòng head API.
3: Component `DataTypeIndicator` trực quan hóa loại dữ liệu (tabular, timeseries, mixed) mà hệ thống API trả về.
4: Tích hợp `ModelSelector`: cho phép người dùng tùy chỉnh model manual (TranAD, BiLSTM...) hoặc phó thác cho Backend auto.

## Tasks / Subtasks

- [ ] Task 1: Drag-Drop Target Component (AC: 1)
  - [ ] Implement `{bafrontend}/src/components/Upload/CSVUploader.tsx`. Use `react-dropzone` wrapper restricting `.csv` mimetypes strictly.
  - [ ] Reject files crossing the 100MB payload warning UI elements visually blocking submission states.
- [ ] Task 2: Data Previews & Identifiers (AC: 2, 3)
  - [ ] Implement query fetching `/api/v1/upload/{id}/preview` once uploaded mapping properties to the UI component `CSVPreview`.
  - [ ] Design a badge logic component `DataTypeIndicator` displaying tags (`Time-series/Purple`, `Tabular/Blue`, `Mixed/Yellow`).
- [ ] Task 3: Selection Configs (AC: 4)
  - [ ] Build a dropdown `ModelSelector` exposing `{ auto: 'Auto Detect', bilstm: 'BiLSTM', tranad: 'TranAD', anogan: 'AnoGAN' }`. Default to Auto.

### Patterns & Conventions

- Maintain client-side strict validation preventing unnecessary backend network bandwidth overhead on invalid dumps. Let UX inform immediately.
- Use `useEffect` or SWR/React Query for reactive preview loading following drop.

### Tech Stack

- `react-dropzone`
