```
├── redis (alpine)            :6380 --> :6379
├── minio (latest)            :9000 (API), :9001 (Console)
├── backend (FastAPI)         :8000
├── celery_worker             (Redis broker, main-queue)
└── frontend (Next.js)        :3000
```

### Service Dependencies
- `backend` --> `db`, `redis`, `minio`
- `celery_worker` --> `redis`, `db`
- `frontend` --> `backend`

### Environment Variables
- `DATABASE_URL`: `mysql+pymysql://user:password@db:3306/csv_agent` (sync for Celery) / `mysql+aiomysql://...` (async for FastAPI)
- `REDIS_URL`: `redis://redis:6379/0`
- `MINIO_URL`: `minio:9000`
- `NEXT_PUBLIC_API_BASE_URL`: `http://localhost:8000/api/v1`
