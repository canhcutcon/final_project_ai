## General Rules

- **Language**: Python 3.10+ (enforced via `setup.py` `python_requires=">=3.10"`)
- **Type Hints**: Used consistently across all modules. Union types written as `X | Y` (Python 3.10+ syntax). E.g. `dict[str, Any] | None`, `str | Path`.
- **Docstrings**: Google-style docstrings on all public classes and methods. Include `Args:` and `Returns:` sections.
- **Logging**: Centralised via `utils.helpers.get_logger(name)`. Format: `[HH:MM:SS] module — LEVEL — message`. `%s` formatting used (not f-strings) for performance.
- **String format for log messages**: Always `logger.info("... %s", value)` — never f-strings inside logger calls.
- **Imports**: Standard library → third-party → local. Local imports use `from data.xxx import Yyy` / `from utils.xxx import yyy` (flat relative, not `src.data`).
- **File naming**: `snake_case.py` for all modules.
- **Seed management**: All scripts call `set_seed(args.seed)` from `utils.helpers` before any computation.
- **No global state**: All classes receive `config: dict` in `__init__`; config is never a global variable.
- **Config**: YAML-driven via `configs/default.yaml`. Loaded with `utils.helpers.load_config()`. Never hardcode thresholds in code.

## Backend Specific (AI Detection Pipeline)

### Architecture Pattern

The codebase follows a **modular phased pipeline** pattern:

```
scripts/run_pipeline.py          # CLI orchestrator (entry point)
    └── phase1()…phase8()        # One function per pipeline phase
          └── src/data/          # Data modules (one class per concern)
          └── src/utils/         # Shared utilities
```

- **No service layer** — each phase function directly instantiates classes.
- **No DI framework** — dependencies resolved manually via `config: dict`.
- **Single Responsibility**: Each file in `src/data/` owns one concern (e.g., `loader.py` = loading, `cleaning.py` = cleaning, `merger.py` = merging).
- **Class-based modules**: All processing logic lives in classes (`DataLoader`, `SchemaStandardizer`, `DatasetMerger`, etc.).

### Phase Orchestration

```
Phase 1 → DataProfiler.scan_all()
Phase 2 → DataLoader.load_all() + SchemaStandardizer.standardize()
Phase 3 → DtypeCorrector / MissingValueHandler / DuplicateHandler / OutlierFlagger / ColumnShiftDetector
Phase 3b → BusinessRuleValidator.validate_and_flag()
Phase 4 → TabularFeatureEngineer.engineer()
Phase 5 → DatasetMerger (merge_xlsx / merge_csv / combine / join_enrichment) + LabelEngineer
Phase 6 → TemporalFeatureEngineer + TimeSeriesAggregator + WindowCreator
Phase 7 → SyntheticAnomalyInjector.inject()
Phase 8 → FeatureSelector / ScalerManager / DataSplitter / DataValidator + PyTorch tensor export
```

### Error Handling

- **Graceful degradation**: Missing optional columns/files are logged as `logger.warning()` and execution continues (e.g., missing `submit_time` skips the time-series phase entirely).
- **FileNotFoundError** raised for missing required inputs (e.g., config, CSV files).
- **Broad `except Exception`** used only in `DataLoader.load_all()` loop to prevent single-file failures from aborting the entire load.
- **No custom exception classes** — standard Python exceptions used throughout.

### Validation

- Input validation: Schema checks in `SchemaStandardizer` (drop unnamed columns, BOM stripping, snake_case normalization).
- Business rule validation: `BusinessRuleValidator` in `src/data/business_rules.py` — reads rules from `configs/business_rules.yaml`, flags violations as new `_biz_rule_*` columns.
- Output validation: `DataValidator.validate_all()` in Phase 8 checks final splits.

### Data Flow Conventions

- All intermediate DataFrames preserved in `dict[str, pd.DataFrame]` keyed by source filename.
- Intermediate outputs persisted as **Parquet** (`data/processed/*.parquet`) via `utils.io.save_parquet`.
- PyTorch tensors saved as `*.pt` files via `utils.io.save_tensor`.
- Column names normalised to `snake_case` by `SchemaStandardizer._to_snake_case()`.

### Config-Driven Thresholds

All numeric thresholds live in `configs/default.yaml`:
- Cleaning: `cleaning.missing.high_missing_threshold = 0.70`
- Outliers: `cleaning.outliers.iqr_multiplier = 1.5`
- Feature selection: `feature_selection.top_k = 50`
- Splits: `splitting.tabular.train = 0.70`, `val = 0.15`, `test = 0.15`
- Business rules: `configs/business_rules.yaml`
